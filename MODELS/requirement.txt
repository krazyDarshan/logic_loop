Step-by-step

Open the folder that contains your script in VS Code.
Create a virtual environment (recommended):
Press Ctrl + Shift + P → type Python: Create Environment → choose Venv.
Select your Python interpreter.

Open the integrated terminal in VS Code (Ctrl + ``  or View → Terminal).
Install the packages:Bashpip install -r requirements.txtOr install them one by one:Bashpip install pypdf sentence-transformers scikit-learn torch
Run the script:
With file arguments:Bashpython your_script_name.py --cv path/to/resume.pdf --jd path/to/job_description.txt
Interactive mode:Bashpython your_script_name.py
